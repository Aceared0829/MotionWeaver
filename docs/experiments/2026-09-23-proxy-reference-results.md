# 手选跑酷参考与已知代理动画对照

2026-09-23。源骨架逐姿态检查后，为四条动作独立指定参考；不使用随机选帧，也不重新按推理残差选帧。本轮是已经看过的案例研究，不能作为未见测试集泛化结论。

|动作|中间参考源帧|依据|
|---|---|---|
|Catch Hurdle low run|32、52、64|屈身抬腿、高抬腿越障、躯干展开|
|Catch Hurdle med stand|32、46、62|俯身伸展、收腿、回正过渡|

每条还保留资产首尾，共 4～5 个资产参考；位置为原生 30 FPS 源帧。姿态描述不表示已确认障碍接触。实际进入每次模型窗口的参考是窗口内资产参考与窗口边界的并集，逐窗口记录在 JSON 中，不会把窗口外参考压到错误的时间点。

## 两种信息条件

1. 历史24：保持现有窗口24、步长4、延迟8；手选参考只能在已进入窗口后使用。
2. 代理48：相同窗口起点，额外读取已知源动画后续24帧，总窗口48（训练长度范围内），只提交前24帧给原融合过程。假设代理已选定动画、未来动画采样可获得。不是预测未知未来，也不是只靠稀疏参考生成过渡：编码器仍读取整个已知动作窗口。

每种条件都有不加手选参考的对照。比较相同源帧28至末帧前8帧；导数额外帧统一复制窗口末帧，避免历史分支意外读取未来。代理窗口超出动画末尾时保持末帧，条件边界落在最后真实帧。

## 结果

平均关节RMSE，cm，越低越好：

|动作|历史24首尾|历史24手选|代理48首尾|代理48手选|
|---|---:|---:|---:|---:|
|低障碍|11.457|11.409|12.197|12.106|
|中障碍|4.420|4.442|4.471|4.523|
|Mantle|4.589|4.529|4.413|4.362|
|Vault|9.170|9.048|7.647|7.475|

Vault 总改善主要来自上下文变化：9.170→7.647；同一代理窗口内手选参考再改善到7.475。不能把全部收益归因于增加参考。其加速度误差4.188→3.062 cm/帧²，最差帧误差28.674→19.757 cm，仍有明显偏差。

低障碍第54帧：历史首尾22.059、历史手选27.049、代理首尾25.882、代理手选28.706 cm，关键姿态退步。低障碍历史手选方案虽均值略降，P95却从23.350增至25.197。中障碍也未改善。不满足统一替换当前模型的条件。
