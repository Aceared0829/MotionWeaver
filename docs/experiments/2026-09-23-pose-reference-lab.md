# 手选参考姿态实验室

## 硬关键帧对照（2026-09-23）

页面新增第四视图和参考帧误差表：源动作、基线、软参考原始模型输出、硬约束后处理输出。汇总指标为软→硬。用户选择已保留，仍可自行增删。

硬约束在最终窗口融合之后，对局部平移和旋转残差求解最小范数加二阶差分平滑的等式约束问题。旋转残差使用SO(3)主值旋转向量，重建后以四元数组合回原姿态。参考帧精确满足源局部变换；距离所有参考8帧及以上的修正为零。非参考帧的真实姿态不参与修正求解，测试对此作了验证。Root权威不在本层改变。

这是使用已知关键帧的离线约束投影，尤其会提前影响关键帧前的输出；不代表未知未来下的因果实时推理，也不代表模型本身学会精确满足关键帧。范围外参考（源帧28～94以外）显示未计分、未施加约束，不以零误差冒充验证。

用户参考32/34/44/52/56/59，代理48模式：

|指标|软参考|只覆盖参考帧|平滑硬约束|
|---|---:|---:|---:|
|平均关节误差 cm|11.322|9.733|6.903|
|加速度误差 cm/帧²|4.008|9.428|4.186|
|参考邻域加速度误差 cm/帧²|5.198|19.877|5.554|

全部6个参考帧的位置误差为数值零，最大局部旋转误差小于0.000003度。第56帧18.493→0 cm。精确满足是约束构造的结果，不能算作模型预测精度。平滑明显优于直接覆盖，但仍比软输出的加速度误差高，尚不能声称消除抽搐；没有速度等式、接触、碰撞或关节限位保证。旋转接近180度的分支、骨长变化及密集互相冲突的参考需要继续验证。

复现：`python -m inference.profiling.evaluate_hard_constraints`；测试：`python -m unittest inference.profiling.test_hard_pose_constraints`。4项测试通过；实际浏览器确认第56帧显示软18.49 cm、硬0.0000 cm。数据位于 `output/ai_animation_runtime_pose_references/hard_user_references.json` 和 `hard_constraint_comparison.json`。

启动 `Start-PoseReferenceLab.ps1`，或在仓库根目录执行 `.venv/Scripts/python.exe -m inference.profiling.pose_reference_lab`，再访问 http://127.0.0.1:8769 。HTML 需要此服务才能调用模型，不能双击 HTML 后直接推理。

目前接入低障碍翻越源动画，共103帧。逐帧浏览或播放，加入参考卡片，删除卡片，再点“用我的参考运行推理”。支持旋转、缩放、源骨架叠加、历史/代理模式、窗口首尾参考开关、误差曲线及JSON导出。浏览器自动保存当前选帧；服务器缓存最多20次推理结果。

基线始终是同模式的窗口首尾条件。我的方案使用所选帧，可选择保留或取消窗口首尾条件。稳态对照只显示源帧28～94，其余源帧仍可选取。代理模式读取完整已知源窗口中的未来24帧，不是稀疏参考驱动的未知动作生成。当前只显示源及重建骨架，不包含UE蒙皮、环境、代理运动执行。

已实测：浏览器选帧并运行模型、当前参考与旧结果状态区分；API检查基线一致、历史/代理模式、关闭默认边界、负数/越界/小数/布尔参考拒绝。结果导出包含实际运行参数和当前草稿，明确两者是否匹配。

服务仅监听127.0.0.1，不依赖CDN。运行需要仓库现有venv、V2检查点和准备好的原始动画数据。GPU不可用时使用CPU。日志位于 `.build/pose_lab_stdout.log` 与 `.build/pose_lab_stderr.log`。

## 审查后的行为

曲线蓝线固定表示当前结果实际使用的手选参考；修改后的草稿另以黄色虚线显示。指标前始终显示实际运行的窗口模式、边界选项及参考列表；旧结果会明确标记。浏览器禁用持久化存储时，仍可在当前会话选帧和运行，但刷新后不保证保留草稿。

服务校验本机 Host、Origin 和会话令牌，并拒绝非法参考索引、非对象请求与重叠推理。约束函数要求连续递增源帧、有限局部变换、单位四元数、正整数半径和非负平滑权重。缺少条件时明确失败，不把跳帧当作等间隔动画。

审查修复及本轮复测见 [审查记录](2026-09-23-pose-reference-review.md)。之前各实验报告的测试计数为当轮记录，最新验证以该记录为准。
