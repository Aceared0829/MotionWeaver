## 候选规则与页面

复用原生审核服务和页面，增加骨盆、左右手、左右脚的整段轨迹、当前帧位置、来源标签及几何候选。页面轨迹使用现有 UE 厘米显示轴，处理文件仍用 Motion 米制轴。

- 手脚稳定候选：组件空间/记录空间速度不高于手 `0.10 m/s`、脚 `0.15 m/s`，连续样本数至少 `ceil(0.1 × FPS)`。这是低速线索，不能证明地面或墙面接触。
- 姿态候选：双膝夹角均小于 125° 标为“双膝弯曲”，均大于 155° 标为“双膝较直”，其余未知。跳跃收腿、落地缓冲与蹲姿可能重叠，不自动转成站蹲真值。
- 阶段候选：来源起终点；骨盆高度变化超过 3 cm 时标注全段最低/最高帧。这不是已确认的起跳、腾空、落地或支撑阶段。
- 来源语义原文与候选分开保存；接触、阶段真值明确为 unknown，硬约束列表为空。全段轨迹仅供离线观察，不冒充在线可见条件。

observation sidecar 的哈希与动作身份、帧数、FPS 绑定到新审核批次。修改候选须建立新的审核版本，旧 UE 批次没有 sidecar 时原有名单摘要不变。页面标记只保存整条动作结论；逐帧标签编辑不在本轮范围内。

## 使用

在项目根目录执行：

```powershell
# 生成另一批观察数据时必须使用新的 run-id，不覆盖已存在版本。
./.venv/Scripts/python.exe -m data.tools.build.soma_observation --run-id <new-run-id>

# 打开本批次审核。
./.venv/Scripts/python.exe -m data.tools.review.motion_review_server --library E:/MotionWeaverData --native-index E:/MotionWeaverData/reports/soma_observation/20261017_observation_pilot_v1/export-index.csv --port 8780
```

访问 `http://127.0.0.1:8780`。可播放、逐帧、切换五个关节轨迹、跳转高度极值并保存人工备注。
