## 五、HTML 工作稿的使用

### 说明书.html
- A4 纸页预览，每页带页眉页脚，与最终 Word 排版基本一致
- 内部核对注释用 `.note` 类（橙色块），**按 Ctrl+Shift+S 可整体隐藏**（正式导出前必须隐藏）
- 截图占位用橙色虚线框 `.shot`，补图时替换成
  `<figure><img src="../04-界面截图/01-xxx.png"><figcaption>图 6-N　…</figcaption></figure>`

### 源程序.html
- 每页严格 50 行，带行号，行号 1–3000 跨页连续
- **由 `extract_source.py` 生成，不手改**。改选码清单后重跑：
  ```powershell
  .venv\Scripts\python.exe paper\软著\03-源代码文档\extract_source.py
  ```

### 渲染 PDF 预览
```powershell
.venv\Scripts\python.exe paper\build_pdf.py `
  --input "paper/软著/02-软件说明书/说明书.html" `
  --output "paper/软著/05-产出/_preview_说明书.pdf"

.venv\Scripts\python.exe paper\build_pdf.py `
  --input "paper/软著/03-源代码文档/源程序.html" `
  --output "paper/软著/05-产出/_preview_源程序.pdf"
```
