| UE NNE / AnimGraph 闭环 | 「MotionWeaver 的 UE NNE/蒙皮闭环、Mover 接线和模型驱动 Root 均未完成」 | 不具备 |

| CMC / Mover 组件接线 | 「目前只是共享接口，并未完成两种 UE 运动组件的接线、NNE 导出或实时闭环验证」 | 不具备 |
| 多人联机 / 网络同步 | 「多人联机、统一人形模型、重定向与接触修正的职责和验收要求见第一阶段开发方案」 | 不具备 |
| 正式游戏打包与玩法 | 「它不是正式游戏运行时，也未完成完整玩法、打包、多角色并发、网络或 CMC / Mover 接入」 | 不具备 |

| 文本 / 语音驱动生成 | 「文本标签尚未接入这一 VQ 训练入口」 | 不具备 |
| FP16 / INT8 量化与剪枝 | 「导出过程逐值验证权重，未作 FP16/INT8 或有损剪枝」 | 不具备 |
| G1 权重微调自定义 UE 骨架 | 「自定义 UE 训练入口不支持直接加载 G1 权重微调」 | 不具备 |
